# Atmospheric Pollutants Nepal — GEE & Python Analysis Pipeline

**Paper:** *Spatiotemporal Dynamics and Hotspot Analysis of Atmospheric Pollutants in Nepal Using Sentinel-5P and Google Earth Engine (2019–2026)*

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## Overview
This repository contains all the Google Earth Engine (GEE) JavaScript scripts and Python-based analysis pipeline used in the research paper. The pipeline extracts, processes, and analyzes 6 atmospheric pollutants across 5 physiographic zones of Nepal from **January 2019 to December 2026**.

## Repository Structure

```
.
├── gee_scripts/                    # Google Earth Engine (JavaScript) extraction scripts
```

## Requirements

### GEE Scripts
A free [Google Earth Engine account](https://earthengine.google.com/) is required. Copy the contents of each `.js` file into the [GEE Code Editor](https://code.earthengine.google.com/) and run them sequentially. Outputs are exported to your Google Drive.

### Python Analysis
```bash
# Create and activate virtual environment
python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/macOS

# Install dependencies
pip install -r requirements.txt

# Run the pipeline sequentially
cd analysis
python 01_data_preprocessing.py
python 02_descriptive_statistics.py
# ... (run all scripts 01-11)
```

## Data Sources

| Dataset | Provider | Temporal Coverage | Spatial Resolution |

| SRTM Digital Elevation Model | USGS | Static | 30 m |
| WorldPop UN-adjusted | WorldPop Group | 2020 epoch | 100 m |
| MODIS Land Cover (MCD12Q1) | NASA | Annual | 500 m |
